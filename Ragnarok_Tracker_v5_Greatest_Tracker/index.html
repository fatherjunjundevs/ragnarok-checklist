About the Creator

Hi! I’m FatherJunJun, the creator of this fan-made Ragnarok: The New World tracker. I built it to make daily quests, weeklies, multiple characters, resets, notes, priorities, and progress easier to manage across devices.

I plan to keep improving the tracker with fixes, quality-of-life improvements, and useful features based on how players actually use it. Thanks for using the tracker and being part of the community. ⚔️
