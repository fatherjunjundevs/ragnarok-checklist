# Ragnarok: The New World Tracker

Production source: `Ragnarok_Tracker_v5_Greatest_Tracker/`

Vercel is configured to use that folder as the project Root Directory. All live application updates should be made inside that folder. Do not upload a second nested tracker folder at the repository root.

Current release: **v5.1.1**

The tracker includes UTC+7 / 5:00 AM reset handling, Monday weekly reset, multi-character tracking, cloud sync through Vercel + Supabase, offline/PWA support, Prontera music, backups, history, reminders, and Light/Dark/Device appearance modes.
